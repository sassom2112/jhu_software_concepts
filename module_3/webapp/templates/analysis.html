Pull Data

Pull Data checks Grad Café for newly submitted application results, cleans them with the Module 2 code, standardizes program and university names with the local LLM, and adds the new records to the database. Existing records are never changed. Depending on how much new data is available, this can take a few minutes; the page keeps working in the meantime.
